# Сайт для отправки статей в Дзен

Статья = один markdown-файл в папке `articles/`. После отправки файла в репозиторий GitHub сам собирает сайт и ленту `rss.xml`, а Дзен забирает ленту.

## Формат статьи

Файл `articles/<латиницей-через-дефис>.md`:

```
---
title: Заголовок без точки в конце и без эмодзи
date: 2026-10-13T12:00:00+03:00
description: Короткое описание для карточки
image: images/cover.jpg        # необязательно: обложка (от 480×320)
draft: true                    # true = в Дзен попадёт черновиком (по умолчанию)
---

Текст статьи в markdown. ## Подзаголовки, списки, **жирный**, ссылки, ![подпись](images/pic.jpg)
```

Картинки кладите в `static/images/` — они появятся на сайте по адресу `/images/...`.

## Правила Дзена, которые стоит помнить

- Заголовок до 200 символов (лучше до 80), без эмодзи, не КАПСОМ, без точки в конце.
- Текст статьи должен открываться по адресу из ленты — сайт это делает сам.
- Дата в `date` должна совпадать со временем реального выхода статьи.
- Материалы обновляются из ленты 7 дней после первой загрузки, дальше правки только вручную в Студии.

## Подключение к Дзену (один раз)

1. Включить GitHub Pages: репозиторий → Settings → Pages → Source: **GitHub Actions**.
2. В Студии Дзена: Настройки → **Свой сайт** → ввести домен сайта → подтвердить права (Дзен даст HTML-файл или мета-тег). HTML-файл положите в `static/`, мета-тег добавьте в шаблон `PAGE` в `build.py`.
3. Там же отправить ленту `https://<домен>/rss.xml` на проверку (проверка может занять несколько недель).

## Локальная проверка

```
pip install -r requirements.txt
python build.py            # результат в public/
```
